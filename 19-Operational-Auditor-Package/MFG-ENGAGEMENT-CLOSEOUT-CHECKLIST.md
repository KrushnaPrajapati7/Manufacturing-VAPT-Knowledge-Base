# Engagement Closeout Checklist

- [ ] Final asset status assigned for every in-scope asset.
- [ ] Every finding has evidence and disposition.
- [ ] Not-tested / unknown / N/A / out-of-scope states documented.
- [ ] Remediation owners and target dates recorded.
- [ ] Retests completed or explicitly pending.
- [ ] Risk acceptances documented by authorized owner.
- [ ] Temporary accounts/access removed or returned.
- [ ] Test data removed according to agreement.
- [ ] Evidence stored/retained according to classification policy.
- [ ] Third-party data handling completed.
- [ ] OT/ICS changes, if any, reconciled and handed back to owner.
- [ ] Report peer-reviewed.
- [ ] Client review/approval completed as contractually required.
- [ ] Final deliverables transferred through approved channel.
- [ ] Engagement lessons learned recorded.
