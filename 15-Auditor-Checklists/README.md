# Auditor Checklists

This layer turns the Master Asset × VAPT × Knowledge matrix into a standardized assessment workflow.

## Files
- `MFG-AUDITOR-MASTER-CHECKLIST.md` — engagement and phase-level checklist.
- `MFG-AUDITOR-PHASE-CHECKLIST.csv` — machine-readable phase checklist.
- `MFG-AUDITOR-ASSET-CHECKLIST.csv` — 406-asset assessment tracker derived from the master matrix.
- `MFG-AUDITOR-CHECKLIST-QA-REPORT.md` — coverage/quality checks.

## Usage
1. Confirm written authorization and Rules of Engagement.
2. Load the authorized asset inventory.
3. Use the master asset matrix to determine applicable phases and knowledge units.
4. Record status and evidence for each applicable checklist item.
5. Treat OT/ICS and safety-related systems with dedicated safety gates.
6. Convert validated observations into the standardized finding schema.
7. Retest and record residual risk.
