# Standards & Control Mapping

This directory is the standards cross-reference layer for the Manufacturing VAPT Knowledge Base.

## Files
- `MFG-STANDARDS-REGISTRY.csv` — controlled list of primary references and their intended use.
- `MFG-STANDARDS-CONTROL-MAPPING.csv` — assessment-domain-to-standard mapping matrix.
- `MFG-STANDARDS-CONTROL-MAPPING.md` — auditor guidance and interpretation rules.
- `NIST-Manufacturing-Profile.md` — existing manufacturing profile material.
- `Regulatory-and-Contractual-Tailoring.md` — existing tailoring guidance.

## Rules
- Prefer the finalized version of a standard where applicable.
- Record the version/status used in an engagement.
- Do not claim compliance from a VAPT finding alone.
- Use client/regulator/contract requirements to tailor the applicable mappings.
- For OT, preserve safety, reliability and production constraints.
