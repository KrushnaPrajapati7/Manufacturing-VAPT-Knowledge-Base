# NIST Manufacturing Cybersecurity Profile

NIST IR 8183 was developed specifically for manufacturing. The finalized Rev. 1 publication provides CSF 1.1 manufacturing-profile guidance. NIST also published an Initial Public Draft of a CSF 2.0 Manufacturing Profile (IR 8183 Rev. 2 IPD) in 2025.

Use the current applicable NIST Manufacturing Profile version for governance/risk mapping, and clearly label drafts versus finalized publications.

Official:
https://csrc.nist.gov/pubs/ir/8183/r1/final
